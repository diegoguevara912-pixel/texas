# Fábrica web signature

Plugin con 15 comandos para construir sitios de clientes de principio a fin. Empieza con `/fabrica-web-signature`, que va llamando a los demás en orden y se detiene en los puntos de aprobación (concepto, diseño, auditoría y publicación).

Cada cliente vive en `proyectos-web/<cliente>/` con su `estado.md`.

Recomendado junto a este plugin: el plugin oficial **Hostinger Connector** (para leer y desplegar en Hostinger) y el skill **frontend-design**.

Reglas fijas: no se publica sin aprobación explícita, no se inventan testimonios ni cifras, no se guardan contraseñas en archivos, las demos no llevan datos reales de clientes.
