# Biblioteca de la fábrica

Material reutilizable en Markdown simple. El modo ficha parte de aquí y solo completa lo que
cambia por cliente, en vez de redactar todo desde cero.

| Archivo | Para qué |
|---|---|
| `plantilla-ficha.md` | Plantilla que usa `fabrica ficha <cliente>` |
| `revision-antes-de-enviar.md` | Lista de revisión antes de mandar la ficha a Hostinger |
| `bloques-texto.md` | Estructuras de texto en español para adaptar |
| `ejemplos-aprobados/` | Copias de fichas que dieron buen resultado (se crea con el primer proyecto aprobado; quitar datos privados del cliente antes de guardarlas) |

**Obsidian (opcional):** puedes abrir la carpeta `Fabrica-Web-Signature` como bóveda en Obsidian
para leer y editar estos archivos. No hace falta instalarlo ni usar plugins.
