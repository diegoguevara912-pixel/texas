# Revisión antes de enviar la ficha a Hostinger

Marcar todo antes de pegar la ficha (o antes de que Claude la envíe con el conector, solo con tu autorización).

- [ ] No queda ningún texto entre corchetes "[Claude: …]".
- [ ] Todas las secciones tienen su texto final (no instrucciones vagas).
- [ ] Colores en hex y tipografías con nombre exacto.
- [ ] La acción principal es una sola y está clara.
- [ ] Contacto confirmado por el cliente (WhatsApp con código de país, correo, dirección, horarios).
- [ ] Logo y fotos reales listos para subir, o marcados como [PENDIENTE].
- [ ] Nada inventado: sin testimonios, cifras, premios ni precios que el cliente no dio.
- [ ] Si es demo: dice "sitio de demostración" y que no se indexe.
- [ ] Se revisó contra los proyectos anteriores para no repetir el mismo diseño.
- [ ] Después de enviar: anotar los créditos gastados en la tabla de créditos del proyecto
      (`fabrica creditos <cliente> "mensaje" <créditos>`).
