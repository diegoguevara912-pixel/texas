# FÁBRICA WEB SIGNATURE — instrucciones del proyecto

- Esta carpeta es la fábrica de páginas web de Diego. Para cualquier trabajo con clientes usa la skill
  `fabrica-web-signature` (`.claude/skills/fabrica-web-signature/SKILL.md`).
- Para continuar construyendo o mejorando la fábrica, lee primero `PROJECT_STATUS.md`, luego
  `docs/arquitectura.md` y `docs/decisiones.md`. Registra cambios en `CHANGELOG.md`.
- Comandos: `python core/fabrica.py <comando>` (Python 3, solo biblioteca estándar).
- Pruebas de la fábrica: `python -m unittest discover -s tests -v` antes de dar algo por terminado.
- Nunca publicar, borrar proyectos, tocar dominios/DNS ni gastar dinero sin la autorización explícita de Diego.
- Responder en español sencillo: Diego es principiante técnico.
