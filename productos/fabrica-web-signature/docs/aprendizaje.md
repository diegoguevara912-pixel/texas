# Aprendizaje operativo

Lecciones reutilizables de cada proyecto. Claude las lee al empezar proyectos nuevos.
Añadir con: `python core/fabrica.py aprendizaje "lección"`. No es entrenamiento del modelo.

- 2026-10-14 — Windows: un servidor HTTP de Python que responde 403 sin leer el cuerpo de un POST provoca "connection reset" en el cliente. Leer siempre el cuerpo antes de rechazar.
- 2026-10-14 — En este equipo no hay Node ni git: preferir soluciones con Python estándar o sitios estáticos.
